## 🚀 Projetos de Desenvolvimento Registrados

### 1. Certifica ESG AgriFamiliar (2025 – Atual)
- **Natureza:** Desenvolvimento tecnológico e inovação (Em andamento).
- **Descrição:** Ecossistema completo para o campo integrando assistência técnica rural especializada (ATER ESG) e emissão de certificações sustentáveis para a agricultura familiar.
- **Tecnologias:** React 19, TypeScript, Supabase, Tailwind CSS, Leaflet GIS, Three.js 3D, Capacitor.

### 2. MetroOn — Aplicativo de Mobilidade Urbana para o Metrô de Sobral (2024)
- **Natureza:** Desenvolvimento (Concluído). Código: [github.com/ocJew/metroon.app](https://github.com/ocJew/metroon.app).
- **Descrição:** Aplicativo móvel para passageiros do sistema de VLT (Veículo Leve sobre Trilhos) de Sobral-CE, com rotas, itinerários e horários em tempo real.
- **Tecnologias:** React Native, JavaScript, APIs RESTful, UI/UX Mobile.

### 3. Nullbank — Banking Simulation & Transaction System (2024)
- **Natureza:** Desenvolvimento (Concluído).
- **Descrição:** Simulação de operações e regras de negócio bancárias com servidores Apache Tomcat, persistência de transações e arquitetura cliente-servidor orientada a objetos.
- **Tecnologias:** Java, Spring Boot 3, Spring Data JPA, Spring Security, Apache Tomcat, PostgreSQL.

### 4. Sistema Mobile de Gerenciamento de Reservas e Mesas para Restaurantes (2024)
- **Natureza:** Desenvolvimento (Concluído).
- **Descrição:** Aplicativo móvel para automação gastronômica, controle em tempo real de mesas, pedidos e fluxo de atendimento.
- **Tecnologias:** React Native, Firebase Realtime Database.

### 5. UniMove — Plataforma de Integração e Mobilidade Universitária (2025)
- **Natureza:** Desenvolvimento (Coordenador).
- **Descrição:** Plataforma focada em usabilidade e facilitação de fluxos internos de transporte e integração para a comunidade universitária da UFC.
- **Tecnologias:** React, TypeScript, APIs REST.

### 6. Sistema ALPR com Visão Computacional (Placa Detect)
- **Descrição:** Reconhecimento automático de placas veiculares utilizando inteligência artificial (YOLO) e OpenCV, conteinerizado em Docker.
- **Tecnologias:** Python, YOLO, OpenCV, Docker.
